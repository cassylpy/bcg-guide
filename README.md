# 卡介苗灌注小幫手

膀胱內卡介苗（BCG）灌注治療的病人衛教與自我照顧工具。
以 PWA（漸進式網頁應用程式）製作，病人開啟網址後可加入主畫面，使用起來與 App 相同，且可離線使用。

基隆長庚紀念醫院　癌症中心
泌尿道癌個案管理師　林佩諭

## 功能

分成三個階段：灌注前、灌注中、返家。

**灌注前**：輸入灌注日期與時間，自動倒數何時開始限水；出門前五項檢核。

**灌注中**：六個姿勢依序輪替，每個姿勢停留 10、15 或 20 分鐘（預設 20），藥物總停留時間隨之為 1 小時、1.5 小時或 2 小時。翻身提醒可關閉，關閉後仍照總時間計時。計時中螢幕不休眠，開始計時同時啟動六小時消毒倒數並自動登錄該次灌注。

**返家**：消毒倒數與期間注意事項、排尿須知四項勾選、每日飲水記錄。

**提醒頁**：下次灌注與膀胱鏡倒數，可匯出 .ics 加入行事曆（早上的灌注會把限水提醒設在前一晚）。

**紀錄頁**：副作用勾選與嚴重度、療程紀錄表（誘導 6 次、維持 15 次、膀胱鏡 16 次）、一鍵產生回診摘要、備份與還原。

**須知與警訊**：完整衛教內容與就醫判斷準則。

所有資料只存在病人手機的瀏覽器，不會上傳，沒有帳號也沒有後端。

## 部署到 GitHub Pages

1. 建立 repository，把本資料夾的檔案放進去（可放在子資料夾如 `bcg/`）。
2. Settings → Pages → Source 選 `Deploy from a branch`，分支選 `main`，資料夾 `/ (root)`。
3. 等一到兩分鐘，網址會顯示在同一頁。

所有路徑都是相對路徑，放在子資料夾也能正常運作。必須是 HTTPS，PWA 的離線與安裝功能才會生效（GitHub Pages 預設就是）。

**注意**：GitHub Pages 免費方案需要公開的 repository。

## 啟用流量統計

檔案開頭的註解區塊留了兩個掛載點，未填寫時完全不送出任何資料。

**Cloudflare Web Analytics**（頁面瀏覽、來源、裝置、國家、載入速度）：
在 Cloudflare 建立 Web Analytics 站台，取得 token 後，將 index.html 開頭註解中的 `TOKEN` 換掉並取消註解。不需要把網域託管在 Cloudflare。

**Umami**（自訂事件）：
若需要記錄 timer_complete、timer_abort、symptom_log 等九個事件，需另外架設或使用 Umami Cloud，填入網域與 website id。Cloudflare Web Analytics 不支援自訂事件。

## 修改內容

所有文字都在 index.html 裡，直接搜尋要改的句子即可。

- 姿勢與說明：`const POSES`
- 療程次數與分組：`GROUPS`、`renderTables()`
- 顏色：檔案開頭 `:root` 的 CSS 變數
- 聯絡窗口與頁尾：搜尋「林佩諭」

改完請把 `sw.js` 第 2 行的 CACHE 名稱往上加一版（例如 `bcg-v5-0` 改為 `bcg-v5-1`），
已安裝的手機才會取得新版本。
